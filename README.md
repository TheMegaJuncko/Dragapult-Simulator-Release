This is the public repository of Dragapult Simulator, where every releases will be updated.

Dragapult Simulator is a software for Windows that is made to simulate battles against multiple IV spreads of one pokemon (up to all 4096) through different features \& settings, essentially giving easy access to valuable informations such as odds to win CMP, which spreads you could hit a breakpoint against etc.

You may find that this folder doesn't contain any installers. At the time this readme is written (12/08/2025), the simulator has not reached the state of beta. Please look forward to more informations on release dates.

You may contact TheMegaJuncko on discord / X (or twitter) for more information, or, after release, any bug, crash or feedback.
